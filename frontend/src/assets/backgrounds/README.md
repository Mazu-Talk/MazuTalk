# 아바타 배경 이미지

이 폴더(`src/assets/backgrounds/`)에 아래 **정확한 파일명**으로 이미지를 넣으면,
역할극 화면의 VRM 아바타 뒤 배경으로 자동 적용됩니다. (코드 수정 불필요)

`import.meta.glob`이 빌드 시 이 폴더를 스캔하므로, 파일을 추가/교체하고
dev 서버를 재시작(또는 다시 빌드)하면 반영됩니다.

## 장소별 파일명

| 시나리오 | 장소 | 파일명 |
|----------|------|--------|
| 친구에게 인사하기 | 놀이터 | `playground` |
| 감정 표현하기 | 교실 | `classroom` |
| 도움 요청하기 | 교실 놀이 시간 | `classroom_playtime` |
| 갈등 해결하기 | 모래놀이터 | `sandbox` |
| 놀이에 참여하기 | 공원 | `park` |
| 헤어질 때 인사하기 | 유치원 앞 | `kindergarten` |
| (공통 기본값) | — | `default` |

## 지원 확장자

`.jpg` · `.jpeg` · `.png` · `.webp` — 예: `playground.jpg`, `park.png`

## 권장 사양

- 비율: 세로형(아바타 박스가 약 280×360) — 가로형도 동작하지만 위아래가 잘릴 수 있음
- 해상도: 720×960 내외면 충분, 너무 크면 로딩이 느림
- 파일명에 공백/대문자 없이 소문자 그대로 사용

> 파일이 없으면 해당 장소의 **그라데이션 색**(하늘/바닥 톤)으로 자동 대체됩니다.
