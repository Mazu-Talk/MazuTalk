# PRD (Product Requirements Document)

# 1. 제품 개요

## 제품명

마주톡 (MazuTalk)

## 한 줄 소개

자폐 스펙트럼 장애(ASD) 아동이 AI 친구와 역할극(Role-play)을 통해 사회적 의사소통과 감정 표현을 반복적으로 연습할 수 있는 언어치료 보조 플랫폼

---

# 2. 문제 정의

## 현재 문제

ASD 아동은 다음 영역에서 어려움을 겪는다.

- 또래와의 대화 시작
- 감정 표현
- 도움 요청
- 갈등 상황 대처
- 사회적 맥락 이해

기존 치료는 다음 한계가 존재한다.

- 높은 비용
- 치료사 부족
- 지역 접근성 문제
- 제한된 치료 시간
- 반복 훈련 부족

---

# 3. 목표

## Product Goal

AI 기반 역할극 환경을 통해 ASD 아동이 안전하게 사회적 상호작용을 반복 연습할 수 있도록 지원한다.

## Business Goal

- 비대면 사회성 훈련 제공
- 치료 보조 도구 제공
- 보호자 모니터링 지원

---

# 4. 주요 사용자

## Primary User

ASD 아동 (5~8세)

### 특징

- 또래와 상호작용 어려움
- 감정 표현 어려움
- 반복 학습 필요

---

## Secondary User

보호자

### 니즈

- 집에서 사회성 훈련
- 학습 결과 확인
- 발달 변화 추적

---

## Tertiary User

치료사

### 니즈

- 학습 데이터 확인
- 발달 상태 파악
- 추가 훈련 계획 수립

---

# 5. 사용자 시나리오

1. 아동이 학습 시나리오 선택
2. AI 캐릭터 등장
3. 음성으로 응답
4. STT 변환
5. 감정 분석
6. LLM 응답 생성
7. TTS 출력
8. 반복 대화
9. 결과 리포트 확인

# 7. 성공 지표 (KPI)

## 시스템 KPI

- STT 응답 ≤ 2초
- LLM 응답 ≤ 3초
- TTS 생성 ≤ 2초

---

## 사용성 KPI

- 평균 세션 길이 ≥ 5분
- 평균 대화 Turn ≥ 10
- 시나리오 완료율 ≥ 80%
